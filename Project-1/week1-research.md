# Week 1 Research Document

## Introduction

As part of the Distributed Media Processing Microservice project, research was conducted on Redis, Celery, and their role in backend systems.

## What is Redis?

Redis (Remote Dictionary Server) is an open-source in-memory data store used as a database, cache, and message broker.

### Key Features

- In-memory storage
- High-speed performance
- Key-value data structure
- Caching support
- Pub/Sub messaging
- Open-source
