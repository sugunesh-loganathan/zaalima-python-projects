# Redis Notes

## What is Redis?
Redis is an open-source in-memory key-value database.

## Features
- Very Fast
- In-memory storage
- Caching support
- Pub/Sub messaging
- High performance

## Advantages
- Low latency
- Easy integration
- Scalable
- Reliable

## Redis in Our Project
Redis tracks job status:
- Pending
- Processing
- Completed
- Failed
