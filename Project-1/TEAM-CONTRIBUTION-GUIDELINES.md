# Team Contribution Guidelines

## Branch Rules

- Do not commit code directly to the main branch.
- Use your assigned branch for development work.
- Create a Pull Request before merging changes.

## Commit Guidelines

Make at least one meaningful commit per day.

Examples of good commit messages:
- Added image upload endpoint
- Implemented image resize functionality
- Added file storage utility
- Updated project documentation

Avoid commit messages like:
- Update
- Done
- Final

## Code Review Process

- Complete your assigned task.
- Test your changes before pushing.
- Inform the Team Leader after completing your work.
- Wait for review before merging into main.

## Communication

- Report blockers immediately.
- Attend project meetings.
- Update progress regularly.
