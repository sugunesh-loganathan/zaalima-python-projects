# Celery Notes

## What is Celery?
Celery is a distributed task queue system used for background processing.

## Features
- Asynchronous execution
- Task scheduling
- Task retries
- Distributed workers

## Advantages
- Improves application performance
- Handles heavy workloads
- Scalable architecture

## Celery in Our Project
Celery processes:
- Image resizing
- Video compression
- Watermarking
- Media optimization
