# Command Usage

This document explains the basic commands used in Project-2.

## Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Run the Application

Run the main application:

```bash
python app/main.py
```

## Project Commands

The project uses a command-line interface (CLI). Additional commands will be documented as new features are implemented.

## Notes

- Make sure all required dependencies are installed before running the application.
- Configure the `.env` file if environment variables are required.
- Use a virtual environment to manage project dependencies.
