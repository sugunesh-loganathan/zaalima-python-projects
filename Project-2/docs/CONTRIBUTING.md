# Contributing to Project-2

Thank you for contributing to Project-2. Please follow the guidelines below when making changes to the project.

## Branching

Before making any changes, create and work on your own branch. Do not make changes directly to the `main` branch.

For Project-2, use the following branch naming format:

`project2-your-name`

Example:

`project2-srilatha`

## Making Changes

1. Create your own branch from the latest `main` branch.
2. Make the required changes in your branch.
3. Test your changes before committing.
4. Keep your changes focused on the assigned task.

## Commit Changes

Use a clear and meaningful commit message that describes your changes.

Example:

`Update CONTRIBUTING.md`

## Push Changes

Push your branch to the remote repository after committing your changes.

## Pull Request

After completing your work:

1. Push your branch to GitHub.
2. Open the repository on GitHub.
3. Create a Pull Request from your branch to the `main` branch.
4. Provide a clear description of the changes.
5. Wait for the team review before merging.

## Contribution Guidelines

- Do not commit directly to the `main` branch.
- Work only on your assigned branch.
- Keep documentation accurate and up to date.
- Test changes before creating a Pull Request.
- Follow the project's existing structure and guidelines.
- Communicate with the team when changes affect other modules.
