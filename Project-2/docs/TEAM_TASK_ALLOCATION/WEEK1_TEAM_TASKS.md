# Git Workflow

Every developer should:

1. Checkout their own branch.
2. Pull latest changes from their own branch.
3. Complete today's assigned task.
4. Commit meaningful changes.
5. Push to their own branch.
6. Create Pull Request.
7. Wait for review before merge.
