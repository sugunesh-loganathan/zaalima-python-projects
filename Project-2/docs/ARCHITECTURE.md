## Folder and File Description

- `app/` – Contains the main application source code.
- `app/AWS/` – Contains the AWS-related module.
- `app/scanner/` – Contains the Scanner module.
- `docs/` – Contains project documentation.
- `.env.example` – Provides an example environment configuration file.
- `.gitignore` – Specifies files and directories that should not be tracked by Git.
- `README.md` – Provides an overview of the project and basic information.
- `pyproject.toml` – Contains Python project configuration and project metadata.
- `requirements.txt` – Lists the Python dependencies required by the project.
- `setup.py` – Contains project package and setup configuration.

## Documentation Files

The `docs/` directory contains documentation related to the project:

- `ARCHITECTURE.md` – Describes the project architecture and folder structure.
- `CHANGELOG.md` – Records project changes and updates.
- `CONTRIBUTING.md` – Provides contribution guidelines.
- `DOCUMENTATION.md` – Provides an overview of the documentation structure.
- `README.md` – Provides information about the project documentation.
- `TROUBLESHOOTING.md` – Provides troubleshooting information for common issues.
